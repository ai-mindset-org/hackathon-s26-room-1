# Приёмка комнаты

Как гонять: инструмент комнаты получает файлы из `input/` примера и выдаёт
результат. Результат сверяется с `expected.md` **по смыслу**: формулировки
свободные, факты (кто · что · когда · числа) должны совпасть. Итог демо:
«прошло N из M».

Примеры синтетические, собраны по мотивам болей заказчиков комнаты.
Реальные тексты болей в репозиторий не публикуются.

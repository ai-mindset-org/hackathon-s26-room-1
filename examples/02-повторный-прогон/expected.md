# Ожидаемый результат повторного прогона

Прогон по дополненному чату ПОВЕРХ реестра из примера 01:

- «Статус по проекту "Витрина"» — **одна** запись, срок обновлён на **02.09** (не дубль)
- «Цифры по отгрузкам» — помечено **выполненным/закрытым**, из активных ушло
- «Согласовать счёт подрядчику» — без изменений
- Новых дублей ни по одному пункту нет

Ключевая проверка: записей про «Витрину» в реестре ровно одна.

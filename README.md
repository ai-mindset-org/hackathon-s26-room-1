# Комната 1 · Входящий хаос → реестр обязательств

Хакатон AI Mindset S26 «Чужая боль» · 29.08.2026 · 10:00–14:00 CET

## Задача

Операционные дедлайны, задачи и обещания приходят вперемешку: письма, чаты,
PDF, скриншоты расписаний, транскрипты созвонов. Люди переносят их в трекеры
и календари руками, часть теряется, часть всплывает за день до срока.

**Строим:** инструмент, который берёт пачку разнородных входящих (текст письма,
экспорт чата, транскрипт, текст со скриншота) и превращает её в единый реестр
обязательств: что сделать · кто владелец · крайний срок · источник (откуда
взято, с цитатой). Повторный прогон обновляет статусы, а не плодит дубли.

Боли заказчиков этой комнаты: задачи команды из чатов и созвонов → трекер;
дедлайны из писем и скриншотов → календарь; статусы проектов из телеграма,
почты и заметок; договорённости, которые сейчас записываются вручную.

## Как работаем с кодом

- **Fork → ветка → PR.** Агент делает это сам: `gh repo fork ai-mindset-org/hackathon-s26-room-1 --clone`,
  ветка `КОД-УЧАСТНИКА/что-делаю`, `gh pr create --fill`. Мержит лидер комнаты.
- **Один участник — один модуль или папка.** Кто что берёт — решаем в комнате,
  фиксируем issues. Так PR не дерутся между собой.
- Конфликт: `git remote add upstream https://github.com/ai-mindset-org/hackathon-s26-room-1` →
  `git pull --rebase upstream main`.
- Интервью с заказчиками кладём в `docs/interview-КОД.md`.
- **Секретов в репозитории не бывает.** Репо публичный. `.env` в `.gitignore`,
  ключи живут только на вашей машине.
- После каждого мержа гоняем `examples/` — они и есть приёмка.

## Приёмка

В `examples/` лежат входы с ожидаемым результатом (появятся к утру события,
собраны из болей заказчиков). Итог демо: «прошло N из M» + вердикт заказчиков
«решило / не решило». Частичный результат — тоже результат.

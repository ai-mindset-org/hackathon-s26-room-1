## Standard sequence

- Confirm that the personnel reference matches the signed offer record.
- Check the office code before selecting a building route.
- Add the manager name in the HRIS profile when the signed record supplies it.
- Use the local orientation calendar for the event time.
- Review language needs with the facilitator before printing materials.
- Ask reception which desk is operating during building work.
- Record issued equipment against the asset register.
- Send the standard arrival note after the start date is settled.
- Store dietary survey totals outside the personnel record.
- Close temporary visitor badges after the permanent badge activates.
- Review payroll fields under the local payroll timetable.
- Escalate duplicate personnel references to the data-quality queue.

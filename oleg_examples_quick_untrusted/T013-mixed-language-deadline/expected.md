# Смешанный язык и относительный срок

Опорное время: `2027-10-11T09:15:00+02:00`; локаль `es-ES` + `ru` + `en`;
пояс `Europe/Madrid`.

## Требуемое состояние

1. Загрузить подписанный контракт
   - владелец: Лена; статус: открыта
   - срок в источнике: `mañana a las 15:00 Madrid time`
   - нормализованный срок: `2027-10-12T15:00:00+02:00`
   - источник: `input/team-chat.txt`
   - цитата: `Лена, please upload el contrato firmado mañana a las 15:00 Madrid time.`
2. Friday demo
   - тип: событие; статус: уже запланировано; отдельной подготовки нет
   - источник: `input/team-chat.txt`
   - цитата: `Friday's demo is already on the calendar; no prep task from me.`

## Не создавать

- три задачи по языковым фрагментам одной фразы;
- задачу подготовки к demo;
- срок в UTC без сохранения локального времени.

# Обрезанный фрагмент без достаточного контекста

Опорное время: `2027-03-03T10:00:00Z`; локаль `en-GB`; пояс `UTC`.

## Требуемое состояние

Пусто: действие, владелец и подтверждение отсутствуют.

## Не создавать

- задачу на «tomorrow afternoon»;
- владельца из местоимения `they`;
- скрытое действие по догадке.

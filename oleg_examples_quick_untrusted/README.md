# Расширенный синтетический корпус

`examples_test/` проверяет обобщение за пределами трёх демонстрационных
сценариев из `examples/`. Сначала зафиксирована карта пространства входов в
[`MAP.md`](MAP.md), затем по ней создан корпус. Исходные примеры не копируются и
не считаются представительной выборкой.

## Структура

- `index.csv` — один владелец метаданных и тегов покрытия;
- `Txxx-название/input/` — один или несколько синтетических источников;
- `Txxx-название/expected.md` — конечный смысловой результат и отрицательные
  проверки.

Все файлы — синтетические. Сценарии независимы. Относительные даты разрешаются
только от опорного времени в `expected.md`. Формулировка результата свободная,
но факты, конечное состояние, связь обновлений и точная цитата должны совпасть.

## Как оценивать

1. Подать все файлы из `input/` одного сценария как один пакет.
2. Сравнить конечный реестр с разделом `Требуемое состояние` по смыслу.
3. Проверить точное присутствие каждой указанной цитаты в названном источнике.
4. Проверить раздел `Не создавать`: эти даты, события, цитаты и числа не должны
   становиться отдельными обязательствами.
5. Для сценария без обязательств результат должен быть пустым, а не
   «осторожным» списком возможных задач.

Корпус не задаёт единую машинную схему продукта. Он задаёт проверяемое
пользовательское поведение до того, как команда выберет формат вывода.
